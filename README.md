# ⚡ SemanticCache-Core: Smart AI Cache

Stop paying for the same AI requests over and over again! **SemanticCache-Core** is an open-source, ultra-fast local caching system that understands the meaning behind user queries. If a user asks a question similar to a previous one, it instantly serves the cached answer, cutting your AI billing by up to 90% for exactly **$0.00**.

## 🚀 Features
* **Smart Matching:** Looks for intent and shared context rather than exact keyword matching.
* **Instant Responses:** Serves responses in microseconds directly from local memory without invoking external APIs.
* **Zero Cost Infrastructure:** Built to optimize deployment without adding heavy dependencies or subscription costs.

## 🛠️ How to Run (For Users)

### 1. Clone the repository
```bash
git clone https://github.com
cd semanticcache-core
```

### 2. Install dependencies
```bash
pip install -r requirements.txt
```

### 3. Run the Smart Cache Server
```bash
python app.py
```
